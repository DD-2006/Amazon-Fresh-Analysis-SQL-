# Amazon-Fresh-Analysis-SQL
The completed Amazon Fresh Database Analysis project was uploaded to GitHub for version control, project management, and easy access. GitHub was used to store the project files, including the dataset, SQL scripts, ER diagram, dashboard screenshots, and project documentation. The platform provides a centralized repository that enables efficient tracking of changes, collaboration, and project sharing. By hosting the project on GitHub, all project resources are organized in a structured manner and can be accessed, maintained, and updated whenever required. This also serves as a professional portfolio showcasing the implementation of database design, SQL analysis, and data visualization techniques.
